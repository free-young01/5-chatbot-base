# 더뉴빌리지로 오세요 — 구현 현황

> 마지막 확인: 2026-10-31 · 이 문서는 프로듀서와 개발자가 함께 읽는 진행판입니다. 이야기의 결정은 [스토리](STORY.md), 화면과 서버의 상세 약속은 [API 계약](API_CONTRACT.md)에 있습니다.

## 지금 어디까지 왔나요?

이름을 입력하고 마을 사람들과 대화하며 사건을 따라가 세 결말 중 하나에 도달하는 첫 버전이 만들어졌습니다. 컴퓨터에서 자동으로 확인하는 검사 8개는 통과했습니다. **프로듀서에게 공유할 공개 주소는 아직 확인되지 않았습니다.** 실제 AI 대사의 자연스러움, 최종 그림, 공개 주소에서의 전체 시연은 남아 있습니다.

| 항목 | 현재 상태 | 직접 확인할 수 있는 것 또는 남은 일 | 담당 |
| --- | --- | --- | --- |
| 이야기 진행 | 동작함 | 인사부터 축제와 세 결말까지 자동 검사에서 확인함 | 팀장 `suyoung` |
| 인물과 자유 대화 | 추가 확인 필요 | 네 인물의 대화 기능이 있고 실제 AI 응답을 한 차례 확인함. 인물별 말투와 비밀을 밝히는 시점은 직접 시연해야 함 | 팀장 `suyoung` |
| 호감도·일자리·차 키 | 수정 필요 | 기본 결말 경로는 검사했으나, 일자리 제안을 받은 뒤 대화로 점수가 바뀌면 선택지가 달라지는 문제가 확인됨. 귀가 시점의 판정을 고정해야 함 | 팀장 `suyoung` |
| 이어하기 | 추가 확인 필요 | 같은 브라우저에서 새로고침하면 이어짐. Render에서 서버를 재시작한 뒤에도 이어지는지는 확인 전 | 서버 `suyoung`, 화면 `yejoon` |
| 화면 | 추가 확인 필요 | 시작과 첫 이동, 새로고침, 좁은 모바일 화면은 로컬에서 확인함. 세 결말까지 실제 화면 조작은 확인 전 | 팀원 `yejoon` |
| 그림 | 임시 그림 사용 중 | 인물 표정과 장소·결말에 맞춘 임시 그림이 있음. 최종 그림 교체와 대사별 적합성 확인이 필요함 | 팀원 `yejoon`, 프로듀서 |
| Render 공개 시연 | 배포 설정 준비됨 | `render.yaml`에 무료 웹 서비스 설정을 추가함. Render에서 서비스를 만들고 공개 주소의 대화·이어하기를 확인해야 함 | 팀장 `suyoung` |

여기서 **동작함**은 현재 코드와 관련 검사를 확인했다는 뜻입니다. **추가 확인 필요**는 기능은 있지만 실제 시연에서 확인할 부분이 있다는 뜻입니다. **수정 필요**는 알려진 동작 문제가 있다는 뜻입니다. 공개 시연을 마치기 전에는 서비스를 완성했다고 표시하지 않습니다.

## 누가 무엇을 맡나요?

- 팀장 `suyoung`: 이야기 규칙, 인물 대사와 공개 정보, 진행 기록, 서버, Render 설정과 배포.
- 팀원 `yejoon`: 화면, 그림 연결, 모바일 표시와 화면 검사.
- 프로듀서: 최종 그림을 전달하고, 공개 주소에서 대화와 이야기 흐름을 시험해 의견을 남김.
- 함께 결정: 이야기 내용은 [스토리](STORY.md), 화면과 서버가 주고받는 정보는 [API 계약](API_CONTRACT.md)을 먼저 고침. `README.md`, `AGENTS.md`, `docs/`, `requirements.txt`는 공유 문서·파일임.

각 개발자는 자기 브랜치에서 작업하고 `main`으로 검토 요청을 보냅니다. 팀장이 확인한 뒤 합칩니다. 첫 통합 버전은 이미 `main`에 포함되어 있습니다.

## 다음 순서

1. 팀장이 일자리 판정 문제를 고치고, 인물 네 명의 대화를 사건 전후로 시험합니다.
2. 팀원과 프로듀서가 최종 그림을 연결하고 모바일 화면과 답변별 그림을 확인합니다.
3. 팀장이 [Render 배포 안내](RENDER-GUIDE.md)에 따라 공개 주소를 만듭니다.
4. 프로듀서가 [시연 안내](PRODUCER_TEST_GUIDE.md)를 따라 세 결말과 이어하기를 시험하고, 팀이 결과와 공개 주소를 [README](../README.md)에 기록합니다.

## 이 문서를 갱신하는 규칙

기능을 구현하거나 고칠 때마다 **같은 변경 작업에서 이 표도 갱신**합니다. 무엇이 실제로 되는지, 무엇을 시험했는지, 무엇이 남았는지를 개발 용어 없이 씁니다. 확인하지 않은 동작은 완료로 표시하지 않습니다. 공개 배포 상태는 실제 주소에서 확인한 뒤에만 바꿉니다. 상세 기술 내용이 필요하면 [API 계약](API_CONTRACT.md)이나 관련 코드·검사에 기록합니다.
