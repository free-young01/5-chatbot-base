# 문서 지도

이 저장소의 자료를 **출처**와 **독자**로 구분한다. 여기서 *대화 모델*은 게임 실행 중 인물 대사를 만드는 OpenAI 모델이고, *구현 에이전트*는 코드를 수정하는 AI 에이전트다. 둘은 읽는 자료가 다르다.

## 우리 팀이 만든 문서

| 문서 | 독자 | 용도 |
| --- | --- | --- |
| [구현 현황](IMPLEMENTATION_SPEC.md) | 프로듀서·개발자·구현 에이전트 | 쉬운 말로 쓴 현재 동작, 남은 일, 담당자. 기능을 바꿀 때마다 갱신 |
| [스토리](STORY.md) | 사람·구현 에이전트 | 인물, 사건 순서, 점수와 세 엔딩의 서사 기준 |
| [API 계약](API_CONTRACT.md) | 두 개발자·구현 에이전트 | 서버와 화면의 요청·응답, 오류, 이미지 선택기 규격 |
| [구현·협업](TEAM_IMPLEMENTATION.md) | 두 개발자·구현 에이전트 | 파일 소유권, 브랜치·PR 절차 |
| [Render 배포 안내](RENDER-GUIDE.md) | 팀장·구현 에이전트 | 공개 시연 주소를 만드는 절차와 확인 항목 |
| [프로듀서 시연 안내](PRODUCER_TEST_GUIDE.md) | 프로듀서·개발자 | 공개 주소에서 이야기와 화면을 시험하는 순서 |
| [프로젝트 AGENTS.md](../AGENTS.md) | 구현 에이전트, 검토하는 사람 | 에이전트가 작업할 때 따를 저장소 지침 |

이 문서들은 **대화 모델의 런타임 프롬프트에 통째로 들어가지 않는다.** 코드를 바꾸는 에이전트는 관련 문서를 읽고, 사람은 기획·계약·진행 상황을 확인한다. 진행 상태는 구현 명세에, 이야기 결정은 스토리에, API 변경은 계약서에 기록한다.

## 실행 중 대화 모델이 실제로 받는 자료

| 자료 | 출처 | 사용 방식 |
| --- | --- | --- |
| `config/chatbot_config.json`의 선택된 인물 `persona` | 팀이 베이스 설정 파일을 수정 | 해당 인물의 성격·말투·현재 공개 가능한 설정을 지시문에 넣음 |
| `data/knowledge/facts.json` | 팀 신규 | `services/retriever.py`가 현재 인물·장면·획득 단서로 먼저 제한하고, 질문에 맞는 사실만 최대 3개 전달 |
| 암호화된 진행 토큰의 해당 인물 최근 대화 | 실행 중 생성 | 해당 인물과의 최근 대화 문맥만 전달 |

`docs/*.md`, `AGENTS.md`, `data/knowledge/example_lore.md`는 대화 모델에 전달되지 않는다. 이미지 목록 `data/images/catalog.json`은 모델 입력이 아니라 **모델이 반환한 표정 단서로 화면 이미지를 고를 때** 사용한다. 자료 접근을 바꾸면 이 표와 관련 테스트를 함께 갱신한다.
