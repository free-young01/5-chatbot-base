# 프로듀서 시연 안내

팀장이 전달한 **공개 주소**를 휴대전화나 컴퓨터의 브라우저에서 엽니다. 설치나 개발 도구는 필요하지 않습니다. 첫 접속에 화면이 늦게 뜨면 잠시 기다려 주세요. 무료 서버가 잠들었다가 다시 켜지는 중일 수 있습니다.

## 한 번 플레이해 보기

1. **마을로 이사하기**를 누르고 이름을 입력합니다.
2. 지미에게 자유롭게 말을 걸어 봅니다. 인물이 이야기 속 상황에 맞게 답하는지, 답변 옆 그림이 어울리는지 봅니다.
3. 화면의 **할 수 있는 일** 버튼을 누르며 캐런의 집, 정육점, 미용실을 방문합니다. 각 인물에게 같은 질문을 해 말투가 다른지도 봅니다.
4. 집으로 돌아온 뒤 캐시를 돕고 지미를 따라 정육점에 갑니다. 지하실 수첩을 발견했을 때 음식의 비밀이 벌써 드러나지 않는지 봅니다.
5. 캐런의 집에서 사진을 찾고 집에 돌아옵니다. 이전 대화와 선택에 따라 일자리 제안이 나올 수 있습니다.
6. 축제 음식에서 지미의 금발 머리카락을 찾은 뒤 **도망친다** 또는 **남는다**를 선택합니다.

**세 결말:** 남으면 마을에 동화됩니다. 차 키를 받고 도망치면 탈출합니다. 차 키 없이 도망치면 붙잡힙니다. 다른 결말을 보려면 상단의 **처음부터 시작**을 누릅니다. 탈출을 보려면 사진 사건 전에 이웃을 돕는 대화를 여러 장면에서 해 보세요. AI가 대화 태도를 판단하므로 같은 문장만 반복해도 점수가 계속 오르지는 않습니다.

## 꼭 확인할 것

- 새로고침해도 같은 장소와 발견 기록이 남는가? 같은 브라우저에서 시험해 주세요.
- 실제 인물의 대사가 자연스럽고, 성격이 서로 다른가? 지미가 사라지기 전에 결말을 미리 말하지 않는가?
- 대사 옆 그림, 장소 그림, 결말 그림이 보이고 장면에 어울리는가?
- 휴대전화에서 글을 읽고 버튼을 누르기 쉬운가?
- 오류가 났다면 다시 시도할 수 있는가? 오류가 난 시점과 화면 문구를 적어 주세요.

의견을 보낼 때는 **사용한 공개 주소, 기기, 어디까지 진행했는지, 기대한 모습과 실제 모습**을 적어 주세요. 비밀 키나 개인 정보는 보내지 마세요. 현재 확인된 일자리 선택지 문제와 추가 확인이 필요한 항목은 [구현 현황](IMPLEMENTATION_SPEC.md)에 적혀 있습니다.
