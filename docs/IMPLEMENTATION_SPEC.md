## 3. API 및 화면 계약

모든 성공 응답은 `{ "state_token": "...", "events": [...], "view": {...} }`이다. `events`는 이번 요청의 새 대사·생각, `view`는 공개 가능한 현재 장소·배경·인물·행동·발견 기록·엔딩이다. 호감도와 차 키는 화면에서 계산하거나 직접 노출하지 않는다.

| 요청 | 입력 | 성공 | 검증 책임 |
| --- | --- | --- | --- |
| `POST /api/session` | `player_name` | 201, 새 진행과 지미의 첫 인사 | 이름 1~50자 |
| `POST /api/session/resume` | `state_token` | 200, 사건 추가 없이 현재 화면 복원 | 토큰 복호화·버전 검증 |
| `POST /api/chat` | `state_token`, `character_id`, `message` | 200, 선택 인물의 답변·이미지와 갱신된 토큰 | 현재 대화 가능 인물, 메시지 1~2000자, 모델 결과 형식 |
| `POST /api/action` | `state_token`, `action_id` | 200, 허용된 이동·조사·선택 결과 | 현재 `view.available_actions`의 ID인지 검사 |

입력 오류는 400, 장면상 불가능한 요청은 409, 긴 메시지는 413, 모델·서버 실패는 500이다. 실패 응답은 `{"error":{"code":"...","message":"..."}}`이며 이전 토큰으로 재시도할 수 있어야 한다. 인물별 최근 대화와 공개된 단서는 토큰 안에 보관한다. `STORY_STATE_KEY`는 로컬 `.env`와 Render 비밀 환경 변수에만 둔다. 자세한 필드·코드·이미지 선택기 시그니처는 [API 계약서](API_CONTRACT.md)를 따른다.

| 담당 | 책임 | 주로 수정할 곳 |

| 다른 개발자 | 장소·인물·대화·생각 기록 화면, 이미지 목록·선택, 화면 검증 | `templates/`, `public/assets/`, `services/image_selector.py`, `data/images/`, 화면 관련 테스트 |

첫 통합 구현은 `lee`에서 완료했으며 위 표는 **이후 수정의 소유권**이다. `README.md`, `AGENTS.md`, `docs/`, `requirements.txt`는 공유 파일이다. API 변경은 두 개발자가 먼저 [계약서](API_CONTRACT.md)를 고친 뒤 각자 담당 파일에 반영한다. 각자 브랜치에서 PR을 올리고 팀장이 검토해 `main`에 병합한다.

## 5. 다음 구현·검증 순서

1. **대화 시연 검토 — 팀장:** 지미·캐런·밥·캐시에게 장면 전후 같은 질문을 해 말투, 기억, 비밀 공개 시점과 이미지 표정을 확인한다. 필요하면 페르소나·공개 사실을 조정한다. 호감도 70점 기준은 시연 결과를 보고 조정한다.
2. **최종 이미지 교체 — 다른 개발자·프로듀서:** 임시 SVG를 제작 자산으로 교체하고 `data/images/catalog.json`의 표정별 경로를 맞춘다. 모든 이미지 URL과 모바일 배치를 확인한다.
3. **통합·배포 — 팀장:** `lee` 변경을 PR로 검토해 `main`에 병합한다. Render에 `OPENAI_API_KEY`와 지속적으로 유지할 `STORY_STATE_KEY`를 설정해 배포한다.
4. **공개 URL 수락 검사 — 두 개발자:** 이름 입력부터 세 엔딩까지 각 한 경로, 새로고침·Render 재시작 후 복원, 모델 실패 표시, 모바일 화면과 이미지 로딩을 확인한다. 결과와 공개 URL을 README에 기록한다.

현재 자동 테스트는 `python -m unittest discover -s tests -v`로 **8개 통과**했다. `lee`와 `origin/lee`는 현황 확인 시 같은 커밋을 가리켰고, `lee`의 구현은 `origin/main`에 아직 포함되지 않았다. 이 문서 이후 변경은 다시 동기화 여부를 확인한다. 로컬에서 사용한 시스템 Python으로 검증했으며 팀의 `conda activate chatbot-base` 환경과 Render 공개 URL은 아직 별도 검증이 필요하다.
